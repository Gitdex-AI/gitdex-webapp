# Security

## Reporting a vulnerability

Email **support@gitdex.ai** with a description, the steps to reproduce and what an attacker could do. Please do not open a public issue or pull request for a vulnerability.

Reports are read by the operator, Paworld Labs LLC. You can expect an acknowledgement, and to be told when a fix is live. Allow reasonable time for that fix before disclosing anything publicly.

## Scope

- The code in this repository.
- The service at `gitdex.ai`, including `/api/v1/*`, `/mcp` and `/mcp/public`.

When testing against the live service, use your own account and your own records, and keep request volume low. Do not access or change other people's data, and do not run denial-of-service tests.

Spam, abusive records and other content problems are not security issues: report them with the report button on the record or the `report_content` operation.
